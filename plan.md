# План реализации tmdb_flutter

Коммерческий перенос [tmdb_kmp](https://github.com/Patotski-AS/tmdb_kmp) (ветка `dev`) на Flutter.
Приложение — учебный проект: каждый этап оставляет запускаемый продукт и добавляет одну практику.

Источник поведения — `tmdb_kmp`, не старое Android-приложение TMDb.
Каталог сетевой. Избранное хранится на аккаунте TMDB. На устройстве остаются сессия и набор id избранных фильмов в памяти.

## Стек

| Задача | Библиотека |
|---|---|
| Состояние экрана | `flutter_bloc` |
| Маршруты | `go_router` |
| Сборка зависимостей | `get_it` |
| Сеть | `dio` |
| Модели и состояния | `freezed`, `json_serializable` |
| Сессия | `flutter_secure_storage` |
| Постеры | `cached_network_image` |
| Браузер и YouTube | `url_launcher` |
| Шиммер | `shimmer` |
| Строки | `flutter gen-l10n`, локаль `ru` |
| Линтер | `very_good_analysis` |
| Тесты | `bloc_test`, `mocktail` |

Платформы: Android, iOS, desktop.

Ключ TMDB передаётся как `--dart-define=TMDB_ACCESS_TOKEN=...` и в git не попадает.
Запросы используют Bearer-токен v4 и `language=ru-RU`.

## Структура

Pub workspace.

```text
tmdb_flutter/
├── pubspec.yaml
├── apps/tmdb/
└── packages/
    ├── design_system/
    ├── networking/
    ├── auth/
    ├── tmdb_client/
    ├── feature_media/
    ├── feature_details/
    ├── feature_person/
    └── feature_profile/
```

`apps/tmdb` собирает `go_router` и регистрации `get_it`. Бизнес-логики в приложении нет.

`tmdb_client` публикует модели и репозитории из `lib/tmdb_client.dart`.
Dio, DTO и мапперы лежат в `lib/src/`. Чужие пакеты `src` не импортируют (`implementation_imports`).

Пары пакетов `api`/`impl` не создаём. Отдельный клиент поиска не создаём: поиск живёт внутри каталога.

## Правила зависимостей

```text
apps/tmdb
  → feature_*, tmdb_client, auth, networking, design_system

feature_media      → tmdb_client, auth, design_system
feature_details    → tmdb_client, auth, design_system
feature_person     → tmdb_client, design_system
feature_profile    → tmdb_client, auth, design_system

tmdb_client        → networking
auth               → networking
networking         → ничего из фич и tmdb_client
design_system      → только Flutter
```

Фича не импортирует другую фичу. Переходы между экранами описывает приложение.

## Маршруты

```text
/                 каталог: фильмы, сериалы, люди
/profile          гость или аккаунт
/movie/:id        карточка фильма
/tv/:id           карточка сериала
/person/:id       персона
```

Фильмы, сериалы и люди — состояние каталога, не отдельные маршруты.
Карточка, персона и профиль открываются поверх каталога и закрываются кнопкой «назад».

## Поведение, которое переносим

Гость открывает каталог, поиск, карточку и персону.
Аккаунт добавляет избранное фильмов.

Каталог:

- без фильтра: `movie/popular`, `tv/popular`, `person/popular`;
- с жанром или сортировкой: `discover/movie`, `discover/tv`;
- поиск: `search/movie`, `search/tv`, `search/person`;
- жанры: `genre/movie/list`, `genre/tv/list`;
- сортировка: популярность, дата выхода, оценка;
- пагинация списком в `Bloc`: первая страница, догрузка, конец списка, ошибка, повтор.

Карточка фильма и сериала: `append_to_response=credits,videos,images,recommendations`.
Персона: `append_to_response=combined_credits`.
Размеры картинок берутся из `configuration`.
Видео открывается во внешнем приложении.

Вход: request token, подтверждение на themoviedb.org, затем `session_id`.
Дополнительно — вход логином и паролем.
В хранилище: `session_id`, `accountId`, `username`.
Ответ 401 очищает сессию и возвращает гостя.
Избранное: `movie/{id}/account_states`, `POST account/{id}/favorite`, `GET account/{id}/favorite/movies`.

Профиль повторяет меню `tmdb_kmp`: обсуждения, списки, обзоры, рейтинги, список отслеживания, избранное, API Subscription, правка профиля, параметры.
Рабочий раздел первой версии — избранное. Остальные пункты открывают сайт TMDB.

## Этапы

Каждый этап заканчивается запускаемым приложением.

### 1. Каркас

- workspace и пустые пакеты;
- `apps/tmdb` открывается на Android;
- тема Material 3 в `design_system`;
- `go_router` с заглушками пяти маршрутов;
- `very_good_analysis`, `arb` с локалью `ru`.

Готово, когда приложение запускается и переходы по заглушкам работают.

### 2. Сеть и клиент TMDB

- `networking`: фабрика `Dio`, Bearer, язык, разбор ошибки TMDB, выход по 401 через колбэк;
- `tmdb_client`: модели фильма, `MovieRepository.getPopularMovies`, маппер;
- размеры постеров из `configuration` кешируются в памяти;
- тест репозитория на поддельном `Dio`.

Готово, когда тест получает страницу популярных фильмов без UI.

### 3. Каталог фильмов

- `feature_media`: `MediaBloc` с событиями загрузки, догрузки и повтора;
- сетка постеров, шиммер, пустое состояние, ошибка;
- `cached_network_image`;
- тест `bloc_test` на первую страницу, следующую страницу и ошибку.

Готово, когда на `/` виден список популярных фильмов и прокрутка запрашивает следующую страницу.

### 4. Карточка фильма

- `feature_details` и маршрут `/movie/:id`;
- название, описание, дата, рейтинг, жанры, постер и фон;
- актёры, съёмочная группа, кадры, рекомендации;
- нажатие на актёра и рекомендацию пока ведёт на заглушку;
- тест Bloc: успешная загрузка и ошибка.

Готово, когда из каталога открывается карточка и «назад» возвращает к списку.

### 5. Сериалы, люди и поиск

- переключатель типа внутри каталога;
- те же состояния списка для сериалов и людей;
- строка поиска с задержкой ввода и сбросом;
- нижняя панель фильтров: жанр и сортировка, сброс возвращает популярное;
- `feature_person` и маршрут `/person/:id`;
- карточка сериала на `/tv/:id` использует тот же экран деталей;
- из актёра открывается персона, из фильмографии — карточка.

Готово, когда все три типа контента ищутся, фильтруются и открывают свою карточку.

### 6. Сессия и профиль

- `auth`: состояние «гость / аккаунт», сохранение и восстановление сессии при старте;
- перехват 401 в `networking` вызывает выход;
- `feature_profile`: форма входа, ожидание подтверждения в браузере, выход;
- избранное фильма на карточке доступно только аккаунту;
- список избранного в профиле;
- остальные пункты меню открывают сайт;
- тесты хранилища сессии и Bloc профиля.

Готово, когда после перезапуска аккаунт остаётся вошедшим, избранное совпадает с TMDB, а выход возвращает гостя.

### 7. Desktop и полировка

- сборка desktop тем же кодом;
- широкая сетка каталога;
- атрибуция TMDB в `design_system`;
- проверка сценариев гостя и аккаунта на Android и desktop.

## Вне этого плана

- локальная база каталога;
- отдельный модуль поиска;
- встроенный плеер YouTube;
- списки, рейтинги, watchlist и обсуждения своим интерфейсом;
- английская локаль.
